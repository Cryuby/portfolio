형상 정합

큰 잔차가 결함 때문인지, 관측 방향이나 위치 차이 때문인지 구분하기 위해 비교 조건을 먼저 맞췄습니다.

  • 정상 참조를 공통 좌표계로 정렬하고, 관측 방향별 depth map을 미리 구성해 재사용
  • 여러 시점의 초기 정합 후보를 유지한 채 단계적 ICP 정제 수행
  • 모든 후보를 같은 검증 표본에서 비교하고, 국소 결함의 영향을 줄이는 lower-median 잔차로 최종 위치 선택

잔차 기반 이상점수

한 점의 거리뿐 아니라 주변 영역의 차이도 살폈습니다. 정상 참조 사이의 변동을 기준으로 각 잔차를 보정했습니다.

  • 정합된 정상 참조를 통합하고, 검사 대상에서 정상 형상까지의 최근접 거리 산출
  • 여러 이웃 범위에서 잔차의 평균과 표준편차 추출
  • 정상 참조 하나를 제외한 나머지와 비교하는 leave-one-out 방식으로 보정 분포 구성
  • 경험적 상위 꼬리값을 Fisher-style 로그 집계로 결합해 이상점수 산출

집계값은 이상 순위 점수입니다. 보정된 결함 확률이나 독립성 가정에 따른 가설검정 결과는 아닙니다.

입력 검증

프레임별 특징

분석 스크립트와 YOLO_framework 노트북을 기준으로 정리했습니다. 필드명만 공개하며 참여자 식별값, 원본 영상과 실제 데이터는 제외했습니다.

코드 발췌: 시선–객체 교차 판정 ＋

시선 좌표에 일정 반경을 두고 탐지 박스와 겹치는지 확인하는 함수입니다. 박스에 가장 가까운 점까지의 거리와 시선 반경을 비교합니다.

def point_box_intersect(px, py, r, x1, y1, x2, y2):
    cx = np.clip(px, x1, x2)
    cy = np.clip(py, y1, y2)
    dx = px - cx
    dy = py - cy
    return (dx*dx + dy*dy) <= (r*r)

분석 스크립트의 함수 본문을 그대로 발췌했습니다. 원본 경로와 데이터는 제외했으며, 별도 테스트에는 포트폴리오 점검용 가상 입력을 사용했습니다.

공공기관의 육아 문서와 아동 기록을 참고하는 RAG 기반 상담 서비스입니다. 상담 목적에 따라 검색 자료와 프롬프트를 구분하고, 개인 기록을 답변에 반영했습니다.

역할
RAG 상담 구조 설계·구현 참여, 오류 사례 분석과 사용자 평가, 기능 점검 및 화면 흐름 보완
문제
정보의 출처와 아동의 상황을 함께 고려해야 했습니다. 상담 목적과 관계없는 자료가 검색되면 답변의 초점도 흐려졌습니다.
구현
맘·닥터·영양 AI별 문서 집합과 프롬프트 분리, 검색된 근거와 육아일지 정보를 결합한 개인화 상담
개선
응답 누락과 검색 관련성, 문맥 오류의 재현 조건 기록. 사용자 의견에 따라 안내 문구와 화면 구성 보완
  • LLM
  • RAG
  • Role-based Prompting
  • User Feedback

역할별 검색 자료

개인 기록 반영

공공 문서는 답변의 근거로, 아동 기록은 개인 맥락으로 구분했습니다. 최근 육아일지와 성장 및 생활 정보를 답변에 반영하는 구조를 함께 설계했습니다.

  • 맘 AI의 공감 중심 상담과 닥터 AI의 신중한 의학 정보 등 역할별 표현 기준을 프롬프트에 반영

  • 검색 문서와 육아일지 정보를 생성 맥락에 함께 전달하는 상담 흐름 구현 참여
  • 아동 기록 관리와 상담 기능 연계
  • 상담, 기록 관리와 부모 커뮤니티 기능 구성

오류 재현과 기능 점검

  • 응답 누락, 관련 없는 검색 결과와 육아 상황의 문맥 오류를 유형별로 분류
  • 오류를 다시 확인할 조건과 수정 필요성을 정리해 반복되는 문제부터 점검
  • 검색 문서와 프롬프트를 다시 검토하고 안내 문구, 버튼 배치와 화면별 흐름 보완
  • 기능 안정성과 UI 개선 의견을 함께 검토해 우선순위와 역할 조정

사용자 평가

  • 29명 부모의 초기 사용성 평가와 주관식 의견 분석
  • 아동 기록을 반영한 조언의 상황 적합성과 대화 편의성에 대한 긍정적 의견 확인
  • 응답 속도의 일관성과 맘 AI의 공감 표현 부족을 후속 개선 항목으로 정리
  • 개발 내용과 실제 사용에서 확인한 한계를 HCI Korea 2026 논문으로 정리
